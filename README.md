# 🇧🇷 Brazilian E-Commerce Data Analytics Portfolio

Welcome to my data analytics portfolio using the Olist Brazilian E-Commerce dataset. This repository showcases my ability to extract business insights from complex, real-world data using Python and Business Intelligence tools.

## 🚀 Projects Included

### 1. [E-Commerce Sales Performance Analysis](./1.brazilian-ecommerce)
* **Objective:** Clean, process, and analyze over 100,000 transactions to identify top-performing product categories and revenue distribution.
* **Tools:** Python (Pandas, Matplotlib, Seaborn), Tableau Public.
* **Interactive Dashboard:** 🔗 **[View Tableau Dashboard Here](https://bit.ly/4xtP3dM)**
* **Key Insight:** The **Health & Beauty** and **Watches & Gifts** categories are the highest contributors to overall platform revenue, generating over 1.2M each.
* **View Full Details:** Navigate to the [`1.brazilian-ecommerce`](./1.brazilian-ecommerce) folder to see the complete Jupyter Notebook and specific project documentation.

### 2. [Customer Segmentation - RFM Analysis](./2.customer-segmentation-rfm)
* **Objective:** Segment over 100,000 customers based on Recency, Frequency, and Monetary (RFM) metrics to optimize targeted marketing and retention strategies.
* **Tools:** Python (Pandas, NumPy, Matplotlib, Seaborn).
* **Key Insight:** Identified a massive opportunity with over 32,000 **"Potential Loyalist"** customers, while confirming a healthy baseline retention rate (only ~1,500 churned customers).
* **View Full Details:** Navigate to the [`2.customer-segmentation-rfm`](./2.customer-segmentation-rfm) folder to see the RFM scoring logic, visualizations, and business recommendations.


### 3. [Logistics & Delivery Performance Analysis](./3-delivery-delay-prediction)
* **Objective:** Evaluate supply chain efficiency by analyzing delivery times, identifying delay rates, and calculating delay severity.
* **Tools:** Python (Pandas, Matplotlib, Seaborn).
* **Key Insight:** While the network has a **93.2% on-time delivery rate**, the delayed packages take an average of 10.6 extra days to arrive, with extreme outliers suggesting tracking system anomalies.
* **View Full Details:** Navigate to the [`3-delivery-delay-prediction`](./3-delivery-delay-prediction) folder for the visualization and statistical breakdown.
