# 🛒 Brazilian E-Commerce Sales Performance Analysis (Olist)

## 📌 Project Overview
This project analyzes over 100,000 anonymized e-commerce transactions from Olist (a Brazilian marketplace). The primary objective is to clean, process, and analyze the complex dataset to identify top-performing product categories and extract actionable business insights to drive revenue growth. 

## 📂 Dataset Source
To maintain a clean repository and adhere to data management best practices, the heavy raw data files are not included in this repository. You can access and download the original dataset directly from Kaggle:
🔗 **[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)**

## 🛠️ Tools & Technologies Used
* **Data Extraction & Cleaning:** Python (Pandas)
* **Exploratory Data Analysis (EDA):** Python (Matplotlib, Seaborn)
* **Data Visualization & BI:** Tableau Public

## 📊 Interactive Dashboard
An interactive dashboard was designed to visualize key performance metrics and revenue distribution effortlessly.
🔗 **https://bit.ly/4xtP3dM**

## 💡 Key Business Insights
1. **Top Revenue Generators:** The **Health & Beauty** and **Watches & Gifts** categories are the highest contributors to the overall platform revenue, generating over 1.2M each.
2. **Strategic Recommendation:** Allocate higher marketing budgets and implement cross-selling promotional campaigns targeting these top categories during peak shopping seasons to maximize profit margins.

## 📁 Project Structure
* `olist_analysis.ipynb`: The Jupyter Notebook containing the end-to-end Python code for data cleaning, merging, and exploratory analysis.
* `cleaned_ecommerce_data.csv`: The final, cleaned dataset output generated from the Python script, used for Tableau integration.
